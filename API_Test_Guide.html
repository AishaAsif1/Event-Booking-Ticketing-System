⚙️ Setup Instructions

Before you start Run these commands in order, then leave the terminal open. Every test in this guide requires the server to be running.
Step 1 — Start the backend server 
cd backend
npm run dev
Expected outputServer running on port 5000
Step 2 — Open Postman
  • Create a new Collection called Event Booking API
  • Create an Environment called Local with these variables:
VariableInitial ValueHow it gets set
baseUrlhttp://localhost:5000Manual
organiserToken(empty)Auto-set by Login test
attendeeToken(empty)Auto-set by Login test
organiserId(empty)Auto-set by Login test
attendeeId(empty)Auto-set by Login test
eventId(empty)Auto-set by Create Event test
publishedEventId(empty)Copy from GET Events response
venueId(empty)Copy from GET Events response
categoryId(empty)Copy from GET Events response
Step 3 — Auto-capture tokens (add to Login test's Tests tab) 
// Paste this in the Tests tab of BOTH login requests
const json = pm.response.json();
if (json.token) {
    // For organiser login:
    pm.environment.set("organiserToken", json.token);
    pm.environment.set("organiserId", json.user.id);

    // For attendee login (use this version instead):
    // pm.environment.set("attendeeToken", json.token);
    // pm.environment.set("attendeeId", json.user.id);
}
⚠️ Auth Rate Limit The /api/auth endpoints allow only 10 requests per 15 minutes. All other endpoints allow 100 requests per 15 minutes. If you hit the limit, wait or restart the server to reset.
